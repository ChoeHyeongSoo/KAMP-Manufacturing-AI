## 1. 카드가 담는 것

| 항목 | 계산 |
|---|---|
| 단계 | 경보 = CNN AND MCD 초과, 주의 = CNN 단독 초과 (28번 결과) |
| 모델별 배수 | 점수 / 임계(train 정상 q99) |
| 예측 오차 비중 | CNN 시점 오차 `(e/sd)²`를 창 안에서 채널별로 합해 1로 맞춤 |
| 통계 이탈 상위 3 | MCD 입력 18피처를 train 정상 평균·표준편차로 표준화한 값의 절댓값 상위 3 |
| 운전 상태 | 창 전류 RMS > 125.2면 고부하 추정 |
| 점검 권고 | 오차 비중 1위 채널 → 점검 항목 표 [가정] (상부 진동 → 상단 체결부·커플링·정렬, 하부 진동 → 하단 베이스·마운트, 전류 → 전원·부하 변동·토출 압력, 진동+전류 → 종합 점검) |

예시 문장(실제 이상 창): "[경보] 상부 진동 쪽 이상 의심. CNN 점수가 임계의 51.2배, MCD 점수가 임계의 9.5배. 예측 오차 비중: 상부 진동 74% · 하부 진동 8% · 전류 18%. 정상에서 가장 벗어난 통계: 상부 진동 피크-피크 +35.3σ, … 운전 상태 추정: 저부하. 점검 권고(가정): 상단 체결부·커플링·정렬."

## 2. 발견

### 2.1 근거는 주입한 채널을 가리킨다 (합성 검증) [데이터]

CNN 경보가 난 창에서 카드의 1순위 근거가 주입한 채널과 같은 비율(group_kfold 5개 fold, 합성 4유형 × 강도 4단계).

| 유형 (주입 채널) | 강도 1 | 2 | 4 | 8 |
|---|---|---|---|---|
| 진폭 증가 (상·하부 진동) — CNN / MCD | 0.98 / 0.97 | 0.94 / 0.96 | 0.96 / 0.98 | 0.97 / 1.00 |
| 상하 반대 흔들림 (하부 진동) — CNN / MCD | **0.72** / 0.30 | 0.98 / 0.60 | 1.00 / 0.85 | 1.00 / 0.99 |
| 전류 불규칙 (전류) — CNN / MCD | 0.99 / 0.71 | 1.00 / 0.91 | 1.00 / 0.98 | 1.00 / 1.00 |
| 진동 스파이크 (상부 진동) — CNN / MCD | 1.00 / 0.88 | 1.00 / 0.98 | 1.00 / 0.98 | 1.00 / 0.98 |

- CNN 오차 비중은 약한 경우(상하 반대 흔들림 강도 1)를 빼면 94% 이상이다. 이 유형은 하부 진동에 상부 진동의 일부를 섞은 것이라 상부 진동도 같이 흔들려 오차가 갈린다.
- MCD 편차 피처는 단변량 표준화 편차라 채널 사이 관계 변화를 잘 가리키지 못한다. **1순위 채널은 CNN 오차 비중을 쓰고 MCD 피처는 보조로 둔다.**
- 한계: 주입 유형은 우리가 만든 4종이라 "맞는 원인"이 정의돼 있다. 실제 고장의 원인 분류 성능이 아니다.

### 2.2 실제 이상은 한 채널로 설명되지 않는다 [데이터]

- 실제 이상 창 63개(세그먼트 13개)의 1순위 채널은 전류 30개(48%), 상부 진동 27개(43%), 하부 진동 6개(10%)다.
- 세그먼트마다 다르다. `outlier_3`은 전류 오차 비중 95%(진동 등급 "정상 유사"), `outlier_16` 전류 74%, `outlier_13`·`outlier_18` 상부 진동 71%·74%, `outlier_1`은 세 채널이 비슷하다(40/36/24%). 이상 이벤트 하나 안에서도 이상이 나타나는 신호가 시간에 따라 바뀐다.
- 진동 등급이 "정상 유사"인 `outlier_3`을 전류 쪽 근거가 설명한다. 조용한 이상 세그먼트가 전류 신호로 잡힌다는 31번 결과와 같은 방향이다.

### 2.3 오경보 카드는 임계 바로 위다 [데이터]

- AND 경보가 난 정상 창은 시드 0에서 1개(`normal_283`, 고부하)다. CNN 배수 1.0, MCD 배수 1.7로 두 모델 모두 임계를 간신히 넘었다.
- 실제 이상 창은 CNN 배수가 5.8~71.8(중앙값 14.7)로 전부 5.8 이상이고, MCD 배수는 1.2~258.7(중앙값 6.1)이며 63개 중 13개(21%)가 3 미만이다.

## 3. 시사점과 활용

1. **원인 부위를 단정하지 않는다.** 이상 하나가 여러 신호에 걸쳐 나타나므로 문장은 "어느 신호가 크게 벗어났는지"까지만 말하고 점검 권고는 후보로 제시한다.
2. **경보 신뢰도 표시 아이디어 [추정]**: 두 배수가 모두 임계 바로 위인 경보는 "낮은 신뢰"로 표시할 수 있다. 오경보 사례가 1건이라 일반화할 수 없고, 운영 규칙으로 쓰려면 더 많은 정상 데이터에서 확인해야 한다.
3. **현장 활용 [가정]**: 경보 알림에 카드 문장을 붙이면 점검자가 "상부 진동 우세 → 상단 체결부부터"처럼 확인 순서를 정할 수 있다. 권고 표는 가이드북과 일반 설비 상식에서 온 것이라 현장 정비 기록으로 검증·수정해야 한다.
4. **LLM은 쓰지 않았다.** 템플릿 문장이 결정적이고 재현된다. LLM으로 다듬는다면 카드의 숫자만 입력으로 주고 출력 숫자를 입력과 자동 대조해야 한다. 대회 규정상 외부 API 사용 가능 여부는 확인하지 않았다.

## 4. 한계

- 원인 라벨이 없어 설명의 정확도는 합성 이상으로만 검증했다.
- 모델 시드 0의 가중치로 만든 결과다. MCD 편차는 표준화 단변량 값이라 마할라노비스 거리의 정확한 분해가 아니다.
- 실제 이상 창 63개는 13개 세그먼트에서 나온 것이라 독립 표본 수가 적다.
