# 주제 ③ 프레스 유압펌프 — 진단 결론 재검증 리포트 (03_diagnosis_recheck_CHS)

- 노트북: `notebooks/03_diagnosis_recheck_CHS.ipynb` (실행 결과 포함, 에러 셀 0)
- 목적: 02 진단(`reports/02_diagnosis_deep.md`)의 결론 중 뒤집힐 수 있는 세 가지를 재검증하고, 모델 단계가 그대로 쓰는 전처리·분할 규칙을 코드(`src/preprocess.py`, `src/split.py`)로 확정한다.
- 심사 기준 대응: 1번(누수 가능성 서술 → 차단 증명), 5번(에일리어싱·저장 경로 규명, 사인 잔차 피처), 2번(모델 출발 성능·표준 전처리)

| 재검증 항목 | 게이트 | 판정 | 핵심 수치 |
|---|---|---|---|
| A-1 DC 오프셋의 정체 | 전류 \|DC\| vs 사인 피팅 f Spearman \|rho\| ≥ 0.5 → 에일리어싱 산물 | **아님(G1-b)** | rho −0.036 (n=539, p=0.42) |
| A-2 진동 스케일 동일성 | 잡음 바닥 비율 0.5~2배 → 동일 | **판정 불가(G2-b)** | 비율 0.385 / 0.334, 단 잡음 바닥≈진폭(rho 0.66/0.91) |
| A-3 형식 누수 차단 | 전처리 후 형식 피처 AUC ≤ 0.6 | **채널별 통과(G3-a)** | 1.000 → 진동 0.566 / 전류 0.597 (전체 0.637) |

## 1. A-1. DC 오프셋은 에일리어싱 산물이 아니다 — 세그먼트 평균 제거 유지

**문제.** 60 Hz 구동 전류가 10 Hz 샘플링에 접히면 0 Hz 근처가 되고, 구동 주파수가 조금 벗어나면 0.1 Hz 이하의 느린 정현파가 5초 burst 안에서 DC처럼 보일 수 있다. 그렇다면 02 §2의 "DC 오프셋 = 파일 형식 누수" 결론이 흔들린다.

**방법.** 세그먼트 620개 × 3채널에 `A·sin(2πft+φ)+C`를 최소제곱 피팅(`signal_checks.sine_fit_segment`, f 0.01~5 Hz 로그 격자 500점 + 정밀화). 세그먼트 길이 대비 반 주기 미만인 피팅(선형 추세와 구분 불가, 이상 전류 33%·정상 5%)과 길이 10샘플 미만은 상관 계산에서 제외.

**발견.**
- 전류 |DC| vs f Spearman: 정상 −0.043 (n=528) / 이상 +0.200 (n=11) / 합침 **−0.034** (p=0.42). 진동 −0.153 (AI0) / −0.145 (AI1). f가 낮을수록 |DC|가 커지는 관계가 없다 → DC는 에일리어싱 산물이 아니다.
- 정상 전류는 세그먼트마다 **f = 0.6001 Hz (IQR 0.5987~0.6011), R² 0.9965, 진폭 중앙값 144.6**의 순수 정현파. 02 §3의 zero-crossing 추정 0.57 Hz보다 정밀하며, 실제 구동 주파수 후보는 59.4 / 60.6 Hz.
- 이상 세그먼트 17~20: 피팅 진폭 138 / 99 / 57 / 29(정상 분포 백분위 47 / 0 / 0 / 0), 오프셋 288 / 237 / 188 / 179. **진폭은 줄고 오프셋만 크다** → 구동 주파수 이탈이 아니라 실제 오프셋(그림 `sine_fit_examples.png`: 이상 17은 전류가 80~480으로 전부 양수, 0.6 Hz 성분 소실).

**시사점.** `preprocess.remove_dc(method="mean")` 유지. 02 §3의 "FFT·스펙트럼 분석 무의미"는 "결함 주파수 분석 불가, 단 접힌 0.600 Hz 성분의 이탈은 지표 후보"로 정정한다(A-4).

**활용 아이디어(5번).** 정상 전류가 정현파에 극히 잘 맞으므로 "정현파에서 벗어난 정도"가 곧 이상 지표다: 사인 잔차 RMS(정상 5.66 vs 이상 51.2, 약 9배)·R²(0.9965 vs 0.46)의 세그먼트 단위 AUC 1.000(n=530/17), |f−0.6| 0.999. 1.19 격자 양자화(최대 오차 0.6)로는 만들 수 없는 크기라 형식 누수는 아니지만, 이상 이벤트가 하루 1건이라 "그날 전류 계측 경로가 달랐을 가능성"(날짜 교란)은 배제할 수 없다 → 진폭 피처와 **별도 피처군**으로 두고 ablation·오류분석에서 재검토.

## 2. A-2. 진동 스케일 동일성은 확인하지 못했다 — 한계로 기록, 형상 피처 병행

**방법.** 1차 차분 MAD 기반 잡음 바닥(`signal_checks.noise_floor`, 두 파일 모두 6자리 반올림 후)을 정상 저부하(state1, 304세그먼트)와 이상 조용한 세그먼트 3·19·20에서 비교. 값 해상도 표(`value_step_table`), DC 제거 후 샘플 분포 KS 검정.

**발견.**
- 잡음 바닥 중앙값: 정상 저부하 AI0 0.0614 / AI1 0.0600, 이상 조용 3·19·20 AI0 0.0236 / AI1 0.0201 → 비율 **0.385 / 0.334**(판정 범위 밖).
- 그러나 10 Hz에서는 진동이 광대역으로 접혀 샘플 간 차분이 곧 진폭이라, 정상 안에서 잡음 바닥과 AC RMS의 Spearman이 0.66 (AI0) / 0.91 (AI1). 잡음 바닥 ≈ 진폭의 다른 표현이므로 "게인이 낮다"와 "그 순간 진동이 작았다"를 구분하지 못한다. 이상 나머지 14세그먼트의 잡음 바닥(AI0 0.0711)은 정상 고부하(0.0749)와 같은 수준이라 게인이 체계적으로 낮다고 보기도 어렵다.
- 값 해상도: 정상 진동은 6자리 반올림(최소 간격 1e-6, 고유값 19,124/20,000), 이상 진동은 연속값(1.1e-5, 594/600). float32 왕복 오차 1.0e-8 / 6.0e-8 → 원 데이터는 모두 float32 정밀도, 정상 파일만 내보내기 때 6자리로 잘린 것으로 추정. 전류: 정상 연속값(최소 간격 0.00011), 이상 1.19209 격자 정수배 99.67%·정수 몫 −335~452. **1.19209 ≈ 10 V / 2²³ × 10⁶** → 이상 파일 전류는 ±10 V 24-bit ADC 코드 × 1 LSB(µV) 원시값이라는 가설(추정). 전류 채널의 저장 경로가 두 파일에서 다르다는 결론은 강화된다.
- KS(정상 저부하 11,146 vs 이상 조용 56 샘플): AI0 D 0.217 (p 0.009), AI1 D 0.163 (p 0.09). 표본이 작아 원인 판별 불가.

**시사점.** "이상 파일 진동 RMS 최대 6배"는 물리 신호로 서술하되 게인 차이 가능성을 한계 표에 적는다. A-3에서 진폭 피처를 원시 스케일 / 세그먼트 내 z-score(형상) 두 변형으로 비교한다.

## 3. A-3. 전처리 후에는 형식만으로 파일을 구분할 수 없다 — 차단 증명

**방법.** 세그먼트 620개를 `split.fold_assignment`로 계층화 5-fold(이상 4·4·4·4·5). 피처군별 표준화 + 로지스틱(class_weight=balanced) out-of-fold AUC(`signal_checks.cv_auc_logistic`).
- 형식 피처(`preprocess.format_features`): 소수 자릿수·|DC|·고유값 비율·격자 정수배 비율 — 전처리 전/후 × 진동/전류/전체
- 진폭 피처(전처리 후): RMS·피크·첨도·crest·왜도 × (원시 / z-score 형상)
- 전류 사인 잔차 피처군(A-1 부산물)

**발견** (`results/03_diagnosis_recheck_CHS/leak_ablation.csv`, 그림 `leak_ablation_bar.png`):

| 피처군 | 진동 | 전류 | 전체 |
|---|---|---|---|
| 형식, 전처리 전 | 1.000 | 1.000 | 1.000 |
| 형식, 전처리 후 | **0.566** | **0.597** | 0.637 |
| 진폭(원시), 후 | 0.923 | 0.922 | 0.997 |
| 형상(z-score), 후 | 0.887 | 0.877 | 0.919 |
| 전류 사인 잔차, 후 | — | 0.991 | (진폭+사인 0.9999) |

- 전류는 첫 실행에서 0.657로 초과. 원인은 1.19209 격자 값의 float 표기 자릿수가 값 크기에 따라 달라지는 것 → `unify_format`에 소수 1자리 반올림(최대 값 변화 0.06) 1회 추가로 0.597. 전체 결합 0.637은 고유값 비율(0.517~0.520)·자릿수 평균(0.522~0.560)의 진폭 프록시 잔재이며 |DC|(0.944/0.920/0.891 → 0.500)·격자 비율(1.000 → 0.520)은 완전히 제거됐다. 형식 피처는 모델 입력에 쓰지 않으므로 여기서 멈춘다(E-6).
- 진폭 스케일 정보의 기여 = 원시 − 형상 = 진동 0.04 / 전류 0.05 / 전체 0.08. 게인 차이가 실제라도 형상만으로 0.92가 남는다.
- 진폭+사인 0.9999는 지도 학습·세그먼트 단위·이상 21개의 낙관적 조건이라 2번 모델의 **상한 참고치**이지 목표치가 아니다.

## 4. 모델 단계 반영 (02 §9 갱신분)

| 항목 | 확정 규칙 |
|---|---|
| 표준 전처리 | `preprocess.preprocess(df)` = `add_seg_uid` → `unify_format`(진동 6자리, 전류 1.19209 격자 + 1자리) → `remove_dc(method="mean")`. 모든 노트북이 같은 함수·기본 인자를 쓴다 |
| 형식 피처 | 모델 입력 금지 (진단·리포트 전용) |
| 분할 | `split.group_kfold_seg`(seg_uid 계층화 5-fold) + `split.time_blocks`(정상 시간순 5블록) 둘 다 보고 |
| 피처군 | ① 진폭(원시: RMS·피크·첨도·crest·왜도) ② 형상(세그먼트/윈도우 내 z-score) ③ 전류 사인 잔차(잔차 RMS·R²·\|f−0.6\|) — ③은 날짜 교란 가능성 때문에 별도 ablation |
| 지도 상한 참고 | 세그먼트 로지스틱 out-of-fold AUC 진폭 0.997 / 진폭+사인 0.9999 (`leak_ablation.csv`) |
| 한계 추가 | 진동 게인 동일성 미확인(A-2), 전류 저장 경로 상이(24-bit ADC LSB 가설), 이상 이벤트 1건에 따른 날짜 교란 |
