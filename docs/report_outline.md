## 3. 수치 인용 규칙

- 1초 윈도우(21·22·24~27·29·31)와 2초(28·35·29 일부) 결과는 **같은 표에 섞지 않는다.** 세그먼트 수(1초 정상 530·이상 17, 2초 452·13)와 시간당 환산(413.35 / 352.5)이 다르기 때문이다.
- gkf(5 fold 합산)와 time_block(블록 평균)은 **나란히 쓰되 비교하지 않는다.** F1·fpr 모두 해당.
- 비교표 F1은 `results/model_comparison.csv`의 `f1` 열(any·q 0.99·skip 0)만 쓴다. k-of-n·상태별 행(28 `[2/3]`·`[상태별]`)은 그 규칙 조건이라 대표 조건 표에 넣지 않는다.
- `_sine`·`_rel` 모델은 반드시 "세그먼트 피처 포함" 묶음에 두고 날짜 교란 가능성을 각주한다.
- 근거 수준 태그 **[데이터] / [추정] / [가정]** 는 초안 규칙 그대로. "N분 전 경보", "점진적 열화 예지", 모터/펌프 원인 단정 문장은 쓰지 않는다.
- 식별 정보(소속·이름·도구명)는 본문·그림·파일명 어디에도 넣지 않는다. 노트북은 번호로만 가리킨다.
