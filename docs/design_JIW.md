# 기법 개발 설계 — 오경보·미탐을 함께 줄이는 2단계 경보

> **적용 범위 안내(2026-10-07).** 이 문서는 28번 CNN+MCD 실험의 사전 설계다. 후속 최종 판정 모델은 23번의 **Ridge-VAR `[first_difference]` + MCD `[diff_amp]`**이며, 이 문서의 가설과 수치는 CNN+MCD 비교 실험 기록으로 남긴다.

> 목표: **오경보(FP)와 미탐(FN)을 동시에 줄인다.** 심사 2번(모델)·3번(오류분석)·4번(현장 활용)·5번(차별성)에 걸친다.
> 이 문서는 구현 전 설계서다. §2의 근거 수치는 저장된 가중치로 이미 확인한 탐색 결과이고(`notebooks/scratch/ensemble_probe*.py`), §4 이후의 가설은 아직 검증 전이다.
> 모델 설명은 `docs/model_guide_JIW.md` 참고.

## 1. 출발점: 지금 무엇이 문제인가

| 문제 | 근거 | 심사 |
|---|---|---|
| ① 오경보가 **고부하 운전 구간**에 몰린다 | 예측 계열 고부하 2.7~3.0% vs 저부하 0.0% | 3·4번 |
| ② **약한 초기 이상**은 모든 모델이 못 잡는다 | 합성 강도 0.25에서 전 모델 약 2% (우연 수준) | 2·5번 |
| ③ 한 모델이 **모든 이상 유형**을 잡지 못한다 | 유형별 1위가 모두 다름 (스파이크 CNN, 진폭 MTAD-GAT, 반대 흔들림 DeepSVDD) | 2번 |
| ④ **조용한 이상**(세그먼트 3·19·20)은 일부 모델이 놓친다 | COPOD·HBOS·DeepSVDD가 1초 윈도우에서 outlier_19 미탐 | 3번 |

실제 이상 데이터는 어느 모델이든 거의 다 잡는다(AUC 0.99~1.00). 따라서 **모델을 가르는 기준은 오경보와 약한 이상 탐지력**이다.

## 2. 설계의 근거: 이미 확인한 세 가지 사실

### 사실 A. 서로 다른 계열은 서로 다른 곳에서 오경보를 낸다
오경보 세그먼트 겹침(자카드): 예측·그래프 계열끼리 **0.50~0.62**, 예측 계열 vs MCD **0.00~0.02**.
→ 같은 계열을 합치는 건 소용이 없고, **서로 다른 계열(예측 + MCD)을 합쳐야 한다.**

### 사실 B. AND로 합치면 오경보가 거의 사라지고 실제 이상은 그대로 잡힌다
각 모델의 임계(train 정상 q99)를 그대로 두고 **둘 다 넘을 때만** 경보(AND-고정):

| 규칙 (2초, gkf·tb 평균) | 오경보 (샘플) | 오경보 (세그먼트) | 실제 이상 세그먼트 | 합성 이상 |
|---|---|---|---|---|
| CNN 단독 | 1.2% | 2.3% | 100% | 0.282 |
| MCD 단독 | 0.9% | 3.5% | 100% | 0.090 |
| **CNN AND MCD** | **0.0%** | **0.1%** | **100%** | 0.075 |
| CNN OR MCD | 2.1% | 5.6% | 100% | 0.297 |

⚠ 결합 점수의 q99를 **다시 구하는** 방식(AND-재설정)은 효과가 없었다(세그먼트 오경보 4~5%로 오히려 증가). 임계를 결합 후에 다시 정하면 각 모델이 거른 효과가 사라지므로 **AND-고정**을 써야 한다.

### 사실 C. 오경보와 약한 이상 탐지는 서로 반대로 움직인다
AND는 오경보를 없애지만 약한 이상(강도 1)을 0.334 → 0.027로 잃는다. OR은 약한 이상을 0.359로 조금 올리지만 오경보가 늘어난다.
→ **단일 규칙으로는 "동시 감소"가 안 된다.** 목적별로 다른 단계를 둬야 한다.

## 3. 설계: 2단계 경보

```
 센서 신호 ──▶ 예측 모델(CNN) ─┐
                                ├─▶ 1단계 "주의": 둘 중 하나라도 임계 초과  (OR, 넓게 의심, 미탐 줄이기)
 윈도우 피처 ─▶ 통계 모델(MCD) ─┘
                                └─▶ 2단계 "경보": 둘 다 임계 초과           (AND, 확실한 것만, 오경보 줄이기)
```

| 단계 | 규칙 | 목적 | 기대 |
|---|---|---|---|
| 주의 | CNN **OR** MCD | 약한 이상을 넓게 포착 | 합성 이상 0.30, 오경보 5.6% (감당 가능한지는 §6) |
| 경보 | CNN **AND** MCD | 확실한 이상만 호출 | 오경보 0.1%, 실제 이상 100% |

현장 의미는 "주의 = 점검 대상 목록에 올림", "경보 = 즉시 조치"로 나눠 심사 4번(현장 활용방안)의 조치 프로세스로 연결한다.

## 4. 검증하려는 가설 (구현 후 확인)

| # | 가설 | 확인 방법 | 성공 기준 |
|---|---|---|---|
| H1 | AND-고정의 오경보 감소는 시드·fold에 상관없이 재현된다 | 시드 3개, 9개 분할, 부트스트랩 쌍 차이 신뢰구간 | CNN 단독 대비 세그먼트 오경보 차이의 95% 구간이 0 미만 |
| H2 | AND의 실제 이상 100% 탐지는 합성 강도 2에서도 유지된다 | 합성 이상 강도별 AND 탐지율 | 강도 2에서 CNN 단독 대비 70% 이상 유지 |
| H3 | 결합 파트너는 MCD가 최선이다 | CNN × {MCD, COPOD, HBOS, OCSVM, DeepSVDD}, GAT × 같은 것 비교 | 오경보 감소폭 최대 |
| H4 | 운전 상태별 임계가 예측 모델의 고부하 오경보를 줄인다 | 고부하/저부하 각각 q99 | 고부하 FP 2.7% → 1.5% 이하 |
| H5 | 주의 단계(OR)의 오경보는 연속 규칙(k of n)으로 줄일 수 있다 | `kofn_alarm` k=2,3 / n=3,5 | 오경보 감소폭 대비 탐지 지연 증가폭 |

## 5. 사용할 모델·피처·방법

### 모델 (신규 학습 없음, 저장된 가중치 558개 재사용)

| 역할 | 후보 | 이유 |
|---|---|---|
| 예측 계열 대표 | **CNN (DeepAnT)** | 합성 이상 최고(0.308), 가장 가벼움 |
| 예측 계열 대안 | MTAD-GAT | CNN과 동률, 진폭 증가에 강함 |
| 통계 계열 대표 | **MCD [amp]** | 오경보 최저, 고부하·저부하 분리 학습, 사인 잔차 피처와 결합 시 합성 이상 0.10 → 0.23 |
| 통계 계열 대안 | COPOD, HBOS, OCSVM, DeepSVDD | H3에서 파트너로 비교 |

### 피처 (통계 계열 입력, `11_window_features.parquet`)

| 피처 조합 | 용도 | 주의 |
|---|---|---|
| `amp` 진폭 18열 | **기본** | 날짜 교란 없음 |
| `amp_sine` +사인 잔차 3열 | 약한 전류 이상 보강 | 세그먼트 단위 값, 날짜 교란 가능성 → 기본과 **분리해 보고** |
| `amp_rel` +채널 관계 3열 | 상·하부 반대 흔들림 보강 | OCSVM에서만 효과 확인 |

### 방법

1. **결합**: 각 모델의 q99 임계를 그대로 두고 논리 결합(AND/OR). 점수 평균은 쓰지 않는다(사실 B의 이유).
2. **운전 상태**: 정상 데이터의 `state`(0 = 고부하, 1 = 저부하)로 임계를 나눈다. 상태는 학습 입력이 아니라 **임계 선택**에만 쓴다(추론 시 전류 RMS로 추정해야 하므로 21번의 2-means 경계 125.2를 쓴다).
3. **연속 규칙**: 윈도우별 경보를 세그먼트 안에서 "최근 n개 중 k개"로 묶는다.
4. **평가**: 팀 계약 그대로(gkf 5 + tb 4, train 정상 q99, evaluate 지표) + 합성 이상 + 부트스트랩 쌍 차이.

## 6. 위험과 한계

| 위험 | 대응 |
|---|---|
| 실제 이상이 **1건**이라 "100% 탐지"가 이 한 사건의 뚜렷함 때문일 수 있다 | 합성 이상 강도별 탐지율로 보완, 보고서에 한계 명시 |
| AND는 둘 다 임계를 넘어야 해서 **약한 이상에서 탐지력이 줄어든다**(강도 1: 0.334 → 0.027) | 2단계로 나눠 약한 이상은 "주의"가 맡도록 설계. 주의 단계의 오경보(5.6%)는 연속 규칙(H5)으로 감소 시도 |
| 합성 이상 4종은 내가 설계한 것이라 **이 유형에 유리**할 수 있다 | 보고서에 합성 평가임을 명시 |
| **MCD 임계가 fold마다 크게 흔들린다**(2초 `amp`: gkf 616~1,427, tb 360~595로 최대 4배 차이). 고부하 정상 점수 중앙값은 한 fold(gkf 3)에서 313, 저부하 21로 고부하가 15배 크지만 임계 1,357 대비 여유는 4배 남짓이라 임계가 낮아진 fold에서는 고부하 정상이 임계에 걸릴 수 있다 | H1에서 시드·fold별 오경보 편차(표준편차)를 함께 보고, 임계를 train 정상에서 자체 추정한 결과임을 명시. 상태별 임계(H4)로 고부하 임계를 따로 두는 방안 검토 |
| 사인 잔차 포함 시 날짜 교란 가능 | 기본(amp)과 분리 보고 |
| 조용한 이상(3·19·20)은 평균 제거 후 신호가 약하다 | 예측 모델·MCD 모두 잡았지만 전류 파형 이탈 의존, 한계로 기록 |
