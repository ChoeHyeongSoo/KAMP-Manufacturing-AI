## 센서 부착 위치에 대한 정정 (2026-09-30)

이전 판 자료는 진동 센서가 "펌프가 아니라 모터 몸체"에 있다고 단정했다. 공식 가이드북(`Guidebook_소성가공 예지보전 AI 데이터셋.pdf`) 확인 결과 이 단정은 근거가 없어 정정했다.

| 항목 | 가이드북 원문 | 비고 |
|---|---|---|
| 센서 설치 | "프레스 설비 유압펌프 상/하단에 진동센서를 설치하고 유압펌프 전력선에 전류 센서를 설치" (7쪽), "유압 펌프 외부에 설치된 센서" (10쪽) | 센서는 유압펌프 계통에 설치 |
| 채널 정의 | AI0_Vibration = 상부진동, AI1_Vibration = 하부진동, AI2_Current = 전류 (9쪽) | 상·하부 매핑은 **확인된 사실** (이전 자료의 "매핑 미확인" 정정) |
| 사진 | 그림 3(8쪽): 전기모터 위에 펌프가 이어진 일체형 유압 유닛 | 진동 센서 2개의 정확한 부착 부위(모터 몸체/펌프 몸체)는 글·사진만으로 확정 불가 |
| 주제문 | "유압펌프 **모터**의 상부·하부 진동" | 자료마다 표현이 달라 위치 단정 불가 |

- 팀 문서의 탐지 대상 표현 **"모터-펌프 구동부 이상"** 은 센서가 모터에 있든 펌프에 있든 성립하므로 유지한다. 바뀐 것은 그 **이유**다(센서가 모터에만 있어서 → 부착 부위가 확정되지 않아서).
- 확정하려면 대회 운영진에 진동 센서 부착 부위를 문의한다.
