# docs/reference/ — 참고 자료

보고서·발표자료를 쓸 때 참고하는 설명 자료와 사전 검토 기록. 정식 분석 결과는 `reports/`와 `results/`가 기준이다.

| 파일 | 내용 | 주의 |
|---|---|---|
| `01_domain_eda_JIW.pdf` | 파인블랭킹·유압펌프 도메인 설명, 데이터 구성, 탐색적 분석 (7쪽) | **원시값 기준** 탐색 결과. 형식 누수 차단 전 수치(특히 전류 자기상관·DC 관련)는 `reports/02`·`03`이 우선 |
| `02_equipment_sensors_JIW.pdf` | 유압 계통·센서 위치, 공정 단계, 이상 전파 경로, 상·하부 진동 해석, 센서 위치의 한계 (8쪽) | 공정 그림의 기포·버·압력 요동은 원인 가설에 따른 개념도 |
| `press_animation_JIW.html` | 위 PDF 공정 그림의 움직이는 버전 (브라우저로 열기, 오프라인 동작) | 신호 그래프는 개념 시뮬레이션 |
| `model_screening_JIW.md` | Forecasting·Graph·Distribution 계열 후보 9종 사전 비교 (팀 전처리·분할·지표 적용) | 시드 1개 사전 결과. 정식 결과는 24~26 노트북 |
