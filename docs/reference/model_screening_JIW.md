# 모델 후보 사전 비교 (Forecasting · Graph · Distribution 계열)

2x 모델 노트북 착수 전에 어떤 모델을 올릴지 고르기 위한 사전 비교다. 정식 결과는 24~26 노트북(`results/<노트북명>/metrics.csv`)에서 다시 낸다.
관련 심사 항목: **2번**(모델 비교), **3번**(FP 집중 조건), **5번**(합성 이상 주입 평가).

## 1. 후보 선정 근거

- 계열 구분은 KDD'25 서베이 "Advances in Time-Series Anomaly Detection: Algorithms, Benchmarks, and Evaluation Measures"(Paparrizos et al.)의 분류를 따랐다.
- 계열별 대표 모델은 이 서베이가 인용한 TSB-AD 벤치마크(NeurIPS 2024) 다변량 순위(VUS-PR)를 참고했다.

| 계열 | 후보 | TSB-AD-M VUS-PR | 비고 |
|---|---|---|---|
| Forecasting | CNN (DeepAnT) | 0.31 (원 순위 1위) | 과거 1초로 다음 샘플 예측, 오차 = 점수 |
| | LSTM-AD | 0.31 | |
| Graph | MTAD-GAT | 미포함 | 센서 간·시점 간 graph attention + GRU, 예측·복원 공동 |
| | GDN | 미포함 | 센서 임베딩 그래프, 센서별 편차 최댓값 |
| Distribution | MCD | 0.27 (계열 1위) | 강건 공분산 Mahalanobis |
| | OCSVM | 0.26 | |
| | HBOS / COPOD | 0.19 / 0.20 | 특징 간 독립 가정 |
| | DeepSVDD | 미포함 | 원시 윈도우 → 잠재공간 중심 거리 |

- 서베이의 Graph 계열 대표(Series2Graph, DADS)는 **단변량 전용**이고 긴 연속 시계열이 필요해, 최대 5초 burst로 끊긴 이 데이터에는 맞지 않아 제외했다. 대신 채널 관계를 그래프로 다루는 GNN 계열(MTAD-GAT, GDN)로 대체했다.
- 서베이·TSB-AD 공통 결론: 복잡한 Transformer보다 단순한 CNN/LSTM이 낫고, 통계 방법이 강하다. 또한 **끊긴 타임스탬프 데이터는 연구가 부족한 영역**이라고 명시한다(이 데이터가 해당).

## 2. 평가 설정 (팀 계약 준수)

| 항목 | 설정 |
|---|---|
| 전처리 | `preprocess.preprocess()` (형식 통일 + 세그먼트 평균 제거) |
| 입력 | 시계열 모델: 전처리된 3채널 원신호 / 특징 모델: `11_window_features.parquet` 진폭 18열 |
| 윈도우 | 2초 (`win_s=2.0`), 예측 모델 lookback 1초 |
| 분할 | `group_kfold_seg` fold 0~4, `time_block` k=1~4 (train = block < k) |
| 임계 | train 정상 점수 q99 (`evaluate.threshold_from_normal`) |
| 지표 | `auc`, `fpr_sample`, `fpr_segment`, `delay_median_s` + 운전 상태별 오경보율 + 합성 이상 탐지율 |
| 학습 | 정상만, 시드 1개(0), 30 epoch |

**합성 이상 주입**: 실제 이상은 1건이라 상위 모델이 모두 AUC 1.000으로 천장에 닿는다. 약한(초기) 이상에 대한 탐지력을 비교하려고, test 정상 세그먼트에 EDA에서 본 징후 4종을 강도 0.25·0.5·1·2로 주입하고 test 정상 오경보율 1% 임계에서 탐지율을 쟀다. 주입 후에도 세그먼트 평균을 다시 빼서 표준 전처리와 조건을 맞췄다.

| 유형 | 주입 방식 |
|---|---|
| 진동 스파이크 | AI0 샘플 10%에 ±강도×3σ 충격 |
| 진폭 증가 | AI0·AI1 × (1 + 0.5×강도) |
| 상·하부 반대 흔들림 | AI1에 −0.5×강도×AI0 성분 추가 |
| 전류 불규칙 | AI2에 강도×0.2σ 백색잡음 |

### 3-2. 오경보가 몰리는 운전 상태

`state` 0 = 고부하(전류 RMS 중앙값 157), 1 = 저부하(86). 정상 윈도우만 대상.

| 모델 | 고부하 fpr (gkf / tb) | 저부하 fpr (gkf / tb) |
|---|---|---|
| CNN (DeepAnT) | 0.044 / 0.019 | 0.003 / 0.001 |
| MTAD-GAT | 0.032 / 0.020 | 0.000 / 0.000 |
| LSTM-AD | 0.033 / 0.024 | 0.002 / 0.000 |
| MCD | 0.023 / 0.003 | 0.000 / 0.009 |
| OCSVM | 0.021 / 0.039 | 0.025 / 0.033 |

→ **FP는 저부하가 아니라 고부하에 몰린다.** 진동이 크고 불규칙한 고부하 상태가 이상과 더 닮았기 때문으로 보인다(02 §1 "고부하 구간 오경보 위험" 관찰과 일치). 31 오류분석에서 확인할 조건.

## 4. 계열별 선정

| 계열 | 선정 | 근거 |
|---|---|---|
| Graph | **MTAD-GAT** | 합성 이상 1위(0.30)이면서 fpr_sample 최저 그룹(0.014 / 0.005) |
| Forecasting | **CNN (DeepAnT)** | 합성 이상 2위(0.25), LSTM-AD(0.17) 대비 우세, fold당 소요 시간 절반(4.7초 vs 10.0초) |
| Distribution | **MCD** | fpr_sample 최저 수준(0.010 / 0.008). 합성 이상 탐지는 약함(0.10) |

- OCSVM은 합성 이상 탐지가 MCD보다 높지만(0.23) `fpr_segment`가 0.076 / 0.103으로 커서 제외했다. 22번 노트북 후보(IsolationForest/OC-SVM)와도 겹친다.
- MTAD-GAT와 CNN은 강한 유형이 달라(MTAD-GAT: 스파이크·진폭, CNN: 반대 흔들림) 점수 앙상블 후보다.

## 5. 원시값 실험과의 차이 (누수 영향)

같은 모델을 전처리 없이(원시값) 돌렸을 때와 비교하면 다음과 같다.

| 항목 | 원시값 | 전처리 후 |
|---|---|---|
| 상위 모델 실제 이상 AUC | 1.000 | 1.000 (유지) |
| 합성 이상 1위 | CNN 0.338 | MTAD-GAT 0.30 |
| CNN 전류 불규칙 탐지율 | 0.55 | 0.32 |

→ 원시값 실험의 "CNN이 전류 이상에 가장 강하다"는 전류 DC(형식 누수) 차이를 잡은 결과였다. **02·03 진단의 전처리 필수 결론을 모델 쪽에서 재확인**한 사례로 보고서 1번(누수 진단)에 활용할 수 있다.
