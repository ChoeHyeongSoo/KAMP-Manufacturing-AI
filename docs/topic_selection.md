# 주제 선정 기록

- 확정 주제: **③ 진동·전류 시계열 기반 프레스 유압펌프 이상 조기탐지 및 오경보 분석**
- 후보: ① 사출성형 품질불량 예측 / ③ 프레스 유압펌프 이상 조기탐지 / ④ X-ray 이물질 탐지 (②⑤ 제외)
- 세 후보 모두 데이터 품질 진단을 먼저 수행하고, 진단 결과로 주제를 골랐다.

## 후보별 진단 요약

| 주제 | 핵심 진단 | 판단 |
|---|---|---|
| ① 사출성형 | labeled cn7 1,211행 / rg3 1,182행. 모든 행이 정확히 2회씩 쌍으로 존재하고 라벨 충돌 쌍 cn7 11/17건, rg3 25/25건 → 모호하지 않은 불량 cn7 3개, rg3 0개. cn7 Mold_Temperature_3 전체 AUC 0.894가 불량 밀집 구간 내부에서는 0.606(시간 누수) | 유효 양성 표본이 너무 적어 모델 비교(심사 2번) 방어 어려움 |
| ③ 유압펌프 | 정상 20,000행 / 이상 600행, 세그먼트 599 / 21. 파일 형식 누수(\|DC\| AUC 0.9443, 전류 양자화 0.19% vs 99.67%)와 전류 에일리어싱을 진단으로 규명 | 이상 이벤트 1건이라는 한계는 있으나, 누수 차단 + 정상 기반 이상탐지 + 탐지 지연·오경보율로 모델·오류분석·현장 활용 스토리 구성 가능 |
| ④ X-ray | raw BMP 2,532장. YOLO bbox 중심 1,147개 중 1,145개(99.83%)가 검사기 오버레이 박스 내부 → 라벨이 검사기 판정을 그대로 옮긴 누수 | 라벨 신뢰도 문제로 "이물 탐지" 대신 "검사기 판정 재현"으로 문제 재정의가 필요 |
